# 引数取得

コマンドの処理を実行していく際に引数の値を取得する方法を紹介します。

## 実装

`execute`メソッド等に渡される`CommandArgument`から引数の値を取得することができます。

引数は事前に`getArgsType`で定義した型に変換されてから渡されます。

例えば、以下のような引数型を定義したとします。
```java
public  CommandArgsType getArgsType() {
    return new CommandArgsType()
            .addArgsTypePattern(Integer.class, Double.class));
}
```
すると、コマンドが受け取る`CommandArgument`で以下のように引数を受け取ることができます。
```java
public  CommandResult execute(CommandArgument args) {

    int arg1 = args.getArg(0, Integer.class);
    double arg2 = args.getArg(1, Double.class);

    return new CommandResult("正しい引数を受け取りました!");
}
```
簡単ですね。

`List<Object>`でまとめて取得したい場合は`getArgs`メソッドをお使いください。

---

可変長引数にした場合に使うメソッドも用意されています。

- getArgsCount
  - 引数の数を返します
- argsCountIs
  - 引数の数が、このメソッドに引数として渡したint値と一致していた場合にtrueを返します
  - 概念的に`argsCountIs(3)`は`getArgsCount() == 3`と同じです
- argsIsEmpty
  - 引数が空の場合にtrueを返します
  - 概念的に`argsIsEmpty()`は`argsCountIs(0)`と同じです


---

さて、引数のパターンが1つならここまででいいですが、複数パターンをオーバーロードして定義していた場合はどうするのでしょうか？

もちろん対応できます。

例えば、以下のような引数型を定義したとします。
```java
public  CommandArgsType getArgsType() {
    return new CommandArgsType()
            .addArgsTypePattern(Integer.class, Double.class))
            .addArgsTypePattern(Boolean.class, String.class));
}
```

この定義では

- `Integer`, `Double`のパターン
- `Boolean`, `String`のパターン

がありますよね?

`CommandArgument`には、どちらのパターンが採用されたかの情報を知るためのAPIがあります。

##### Class型配列

引数パターンを`Class<?>[]`クラス型配列で取得する方法です。

取得するには`getArgsTypePattern`メソッドを使います。

このメソッドの戻り値は、`addArgsTypePattern`から登録したクラスが配列で戻ります。

仮に `Integer`, `Double`のパターンが採用されていた場合は

`{Integer.class, Double.class}`のような配列が返るということになります。

条件次第では使いますが、正直言ってあまり使い勝手がよくありません。

次に紹介する方法の方が使い勝手いいです...w

##### パターン番号取得

`CommandArgumnt`は、どのパターンを採用したかの番号を返すAPIがあります。

`getArgsTypePatternNumber`です。

今回の引数パターンの場合、パターン番号は

- `Integer`, `Double`のパターン -> `0`
- `Boolean`, `String`のパターン -> `1`

となります。

これを使うことで

```java
switch(args.getArgsPatternNumber()){
    case 0:
      return intDoublePtnProcess(args);
    case 1:
      return boolStringptnProcess(args);
}
```

のような条件分岐を書くことができます。
