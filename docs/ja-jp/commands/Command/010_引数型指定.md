# 引数型指定

コマンドの引数の型を指定する方法を紹介します。

## 実装

引数の型を指定する場合`getArgsType`メソッドをOverrideしてください。

これをOverrideしない場合やnullを返した場合、型チェックや型変換が実行されません。

### 引数型登録

引数型情報である`CommandArgsType`には`addArgsTypePattern`から引数型のパターンを登録します。
```java
public  CommandArgsType getArgsType() {
    return new CommandArgsType()
            .addArgsTypePattern(Integer.class, Double.class));
}
```

これで、このコマンドは第一引数に`Integer`を、第二引数に`Double`を受け取るコマンドであると定義できます。

この定義をしたコマンドに渡される引数が、引数なしの場合や第三引数以上あった場合は引数不一致としてコマンド自体が実行されません。

引数の数や型を確認済みの安全な状態でコマンドの処理に集中できますね。

しかし、このままでは可変長引数を扱いたい場合にこれでは困ってしまいます。

可変長引数を扱いたい場合は以下のように引数型を定義してください。
```java
public  CommandArgsType getArgsType() {
    return new CommandArgsType()
            .addArgsTypePattern(new CommandArgsTypePattern(false, Integer.class, Double.class)));
}
```
ポイントは、コンストラクタの第一引数に`false`を入れた`CommandArgsTypePattern`のインスタンスを使って定義する点です。

この第一引数の`false`は、引数の数を厳密にチェックするか否かを表しています。

そこに`false`を入れているので引数の数を厳密にチェックしなくなります。

この定義のコマンドに対して第三引数以降の引数はすべて型変換・型チェックが行われずにコマンドまで辿り着きます。

---

ちなみに....

内部処理的には
```java
public  CommandArgsType getArgsType() {
    return new CommandArgsType()
            .addArgsTypePattern(Integer.class, Double.class));
}
```
と
```java
public  CommandArgsType getArgsType() {
    return new CommandArgsType()
            .addArgsTypePattern(new CommandArgsTypePattern(true, Integer.class, Double.class)));
}
```
は全く同じになります。
