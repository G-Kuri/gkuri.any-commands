# 最小構成

コマンドを作成する際の最小構成を紹介します。

実装がこの要件に満たない場合、例外が発生するか正しく処理を実行できません。

## 実装

CommandManagerに登録するコマンドのクラスは

***必ず`Command`クラスを実装***してください。

そして、`Command`クラスに定義されている以下の3メソッドをOverrideしてください。

- getName
- getDescription
- execute

また、各メソッドは以下に従って実装してください。

- getName
  - nullを返さない
  - 空文字列や空白のみの文字列を返さない
- getDescription
  - nullを返さない
  - 空文字列や空白のみの文字列を返さない
- execute
  - nullを返さない

## サンプルコード

以下が`CommandManager`に登録可能なコマンドの最小構成です。

```java
public class SampleCommand implements Command {

    @Override
    public String getName() {
    	return "sample";
    }

    @Override
    public String getDescription() {
        return "サンプルコマンドです";
    }

    @Override
    public CommandResult execute(CommandArgument args) {
        return new CommandResult("サンプルコマンドが実行されました!");
    }

}

```
